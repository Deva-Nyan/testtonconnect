# Anime Chatbot Playground

Этот проект демонстрирует, как собрать собственного рофлового чат-бота в стиле аниме-девочки на базе моделей Hugging Face. Репозиторий содержит утилиты для настройки персонажа, интерактивного общения и парсинга тредов с Двача (2ch.hk) для пополнения датасета.

## 1. Получение кода
1. Создайте локальную папку и клонируйте репозиторий (или скачайте архив):
   ```bash
   git clone <url-до-репозитория> anime-chatbot
   cd anime-chatbot
   ```
2. При необходимости инициализируйте свой собственный репозиторий и сделайте первый коммит:
   ```bash
   git init
   git add .
   git commit -m "Initial anime chatbot commit"
   ```
   **Важно:** ассистент не выполняет push — загрузка изменений в ваш удалённый репозиторий остаётся на вас.

## 2. Подготовка окружения
Для быстрого старта предусмотрены bootstrap-скрипты под разные ОС:

- **Linux/macOS** — запустите Bash-скрипт:
  ```bash
  ./scripts/bootstrap_env.sh
  ```
- **Windows (PowerShell)** — запустите:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap_env.ps1
  ```
  При желании можно явно указать путь к интерпретатору Python, например `-Python "C:\\Python311\\python.exe"`.

Оба варианта создадут виртуальное окружение `.venv`, обновят `pip` и установят пакет в editable-режиме.

Альтернативно, все шаги можно проделать вручную:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

На Windows вместо `source` используйте PowerShell-команду:
```powershell
. .\.venv\Scripts\Activate.ps1
```

## 3. Запуск чата
После активации окружения запустите CLI-чат соответствующим скриптом для вашей ОС:

- **Linux/macOS**
  ```bash
  ./scripts/demo_chat.sh
  ```
- **Windows (PowerShell)**
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\scripts\demo_chat.ps1
  ```

Оба скрипта передают дополнительные аргументы в `python scripts/run_chat.py`, поэтому можно указать, например, путь к пользовательской конфигурации.

> ℹ️  Чат работает и без "памяти" из тредов — бот общается сразу после установки.
> Импорт постов Двача лишь добавляет дополнительный контекст к ответам и является необязательным шагом.

### Быстрый тест генерации

Чтобы убедиться, что модель скачалась и отвечает, воспользуйтесь проверочным скриптом:

```bash
python scripts/check_model.py
```

Скрипт сначала проверит, установлены ли ключевые зависимости (`torch`, `transformers`, `requests`) и доступна ли базовая модель
`tinkoff-ai/ruDialoGPT-medium` (локально или на Hugging Face). После этого он отправит готовый промпт, покажет ответ и завершится с
кодом `1`, если бот выдал запасную реплику.
Также можно выполнить одиночный запрос напрямую через основной CLI:

```bash
python scripts/run_chat.py --test-prompt "Привет!"
```

Скрипт выведет ответ и завершит работу. Для полноценного диалога запустите его без `--test-prompt`.

> 💡  Если хочется поэкспериментировать, передайте в параметр `--model-name` альтернативные модели, например `IlyaGusev/saiga_mistral_lite` или `microsoft/DialoGPT-medium`.

### Добавление "памяти" из тредов
Если заранее собрать треды с Двача, их можно передать в чатбот и тем самым расширить контекст ответов. Сначала скачайте данные:

```bash
python scripts/ingest_thread.py --board b --thread 123456 --out data/dvach.jsonl
```

> ⚠️  Скрипт использует Makaba API и по умолчанию перебирает домены `2ch.hk`, `2ch.pm`,
> `2ch.tf`, `2ch.wf`, `2ch.life` и `2ch.org`. Иногда сервер возвращает HTML вместо JSON (например, при блокировке по IP
> или требовании капчи). В этом случае утилита выведет подсказку — попробуйте повторить
> запрос позже, сменить сеть или воспользоваться одним из ручных режимов ниже.

### Если Makaba блокирует запросы

1. **Попробовать конкретный домен Makaba.** В ряде регионов (например, в РФ)
   `2ch.hk` может быть заблокирован и перенаправлять на зеркала `2ch.org`, `2ch.tf`,
   `2ch.wf`, `2ch.life` и т. д. Передайте подходящие домены явно (опцию можно указать
   несколько раз):
   ```bash
   python scripts/ingest_thread.py --board b --thread 123456 \
       --api-host 2ch.org --out data/dvach.jsonl
   ```
2. **Указать свои заголовки.** Можно передать cookie и User-Agent из браузера, чтобы
   повторить успешно авторизованный запрос:
   ```bash
   python scripts/ingest_thread.py --board b --thread 123456 \
       --cookie "your_cookie_here" --user-agent "Mozilla/5.0 ..."
   ```
3. **Сохранить JSON вручную.** Откройте в браузере ссылку вида
   `https://2ch.hk/makaba/makaba.fcgi?task=get_thread&board=b&thread=123456&json=1`
   (если домен заблокирован, используйте подходящее зеркало — адрес останется тем же).
   После прохождения капчи сохраните JSON в файл и передайте его в скрипт:
   ```bash
   python scripts/ingest_thread.py --board b --thread 123456 \
       --json-file downloads/thread.json --out data/dvach.jsonl
   ```
4. **Сохранить HTML страницы.** Откройте тред в браузере, после прохождения капчи
   сохраните страницу как HTML. Затем выполните:
   ```bash
   python scripts/ingest_thread.py --board b --thread 123456 \
       --html-file downloads/thread.html --out data/dvach.jsonl
   ```
   Парсер извлечёт текст постов прямо из сохранённой страницы.

Для детального логирования используйте флаг `--verbose` — он подскажет, какие шаги
выполняет скрипт и предложит альтернативы при ошибках.

Затем запустите чат с указанием файла:

```bash
python scripts/run_chat.py --memory-file data/dvach.jsonl
```

Или через скрипты:

```bash
./scripts/demo_chat.sh --memory-file data/dvach.jsonl
```

На Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\demo_chat.ps1 -MemoryFile data\dvach.jsonl
```

Бот извлечёт до трёх подходящих сообщений из файла и подставит их в системный промпт перед генерацией.

При первом запуске будет скачана модель `tinkoff-ai/ruDialoGPT-medium`. Вы можете указать другую модель в конфигурации (`anime_chatbot/config.py`).

## 4. Импорт и подготовка данных
Полученный JSONL-файл удобно использовать не только в чате, но и для тонкой настройки модели (см. `anime_chatbot/training.py`).

## 5. Проверка установки
Для быстрой проверки, что код компилируется, выполните:
```bash
./scripts/run_tests.sh
```
Команда прогоняет `python -m compileall` по основным модулям и скриптам.

## 6. Кастомизация персонажа
- `anime_chatbot/config.py` — настройки модели, генерации и приветственного сообщения.
- `anime_chatbot/persona.py` — генерация инструкций и речевого стиля персонажа.
- `anime_chatbot/chatbot.py` — основной класс чат-бота с управлением контекстом.
- `anime_chatbot/data_ingestion.py` — загрузка и очистка тредов Двача.
- `anime_chatbot/training.py` — заготовка для обучения/дообучения на собранных данных.

Создайте собственные конфигурации и передавайте их в CLI-скрипты либо расширяйте пакет новыми модулями.
